# DTR System

Daily Time Record system for HR: imports biometric time-clock exports, computes hours worked,
late, undertime and absences, manages employee records, and produces the DTR in Excel and PDF.

- `api/` — Laravel 11 REST API (PHP 8.2+, MySQL 8, Sanctum)
- `web/` — Next.js + Tailwind CSS front end

Work in progress: setup instructions will follow with the first full version.
